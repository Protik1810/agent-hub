Your token not generated

Your personal admin token: it signs you in on other devices and works with the hub's API. You have one at a time, and it stays valid until you revoke it.

  1. Sign in on another device: open this hub's address there, choose Use a token or sign-in code, and paste your token. (For a quick one-off, the Access panel gives a short sign-in code instead.)
  2. Use the API from scripts and tools: send it as a bearer token. 
    curl -H "Authorization: Bearer YOUR_TOKEN" http://127.0.0.1:7700/api/agents
  3. Keep it to yourself. It controls the whole hub. Agents never get it: each agent gets its own token on the Add agent tab.
  4. If it leaks, revoke it here and generate a new one. Revoking doesn't sign you out of this dashboard.
